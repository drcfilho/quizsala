QuizSala — Mapa de URLs de teste

Só URLs de teste local (servidor php -S na própria máquina). Atualizado em 2026-07-24, depois da T24 (cronômetro, explicação, resumo final e timeout do aluno) — banco recém-recriado com bin/init-db.php + uma segunda sessão de exemplo criada só pra esta página mostrar o estado aguardando. Código de sala e token do professor mudam a cada sessão nova; a senha do admin não muda (só é gerada na primeira vez, ver seção 4).

Servidor de teste: cd public && php -S 127.0.0.1:8080. Todas as URLs abaixo assumem esse endereço.

1. Aluno

Entrada pública — qualquer um com o código da sala chega aqui.

http://127.0.0.1:8080/index.php

Digitar o código de uma sessão ativa: AULA01 respondendo (anônimo, sem pedir nome) ou 8GXACA aguardando (com nome — pede o nome do aluno ao entrar). Depois de entrar, o fluxo continua em prova.php#t=<token do aluno>, um token gerado na hora, não uma URL fixa.

http://127.0.0.1:8080/index.php?s=AULA01 — link direto (é pra isso que serve o ?s=: o QR Code da tela de espera aponta aqui), pré-preenche o código, só falta clicar Entrar

index.php?erro=codigo e ?erro=nome são os dois avisos que a própria tela mostra quando api/entrar.php redireciona de volta (código inexistente/encerrado, ou sessão que exige nome e nenhum foi digitado) — não precisam ser abertos à mão.

2. Painel do projetor

Tela só de leitura, sem interação — fica projetada na parede.

http://127.0.0.1:8080/tela.php — sem código, acha sozinho a sessão ativa mais recente (api/sessao-ativa.php) e volta a procurar se ela sumir http://127.0.0.1:8080/tela.php?codigo=AULA01 — código explícito, trava nessa sessão: prova em andamento (contador "responderam" ao vivo; se a questão atual tiver cronômetro configurado, aparece a contagem regressiva também) http://127.0.0.1:8080/tela.php?codigo=8GXACA — código explícito, tela de espera com QR Code + contador de quantos já entraram

5. APIs (uso interno — o JS já chama sozinho)

Útil abrir direto só pra depurar o JSON cru.

http://127.0.0.1:8080/api/painel.php?codigo=AULA01 — payload que tela.js e admin.js fazem poll a cada 2s (muda de formato por fase: temporizador só existe em respondendo com cronômetro configurado; distribuicao/explicacao só em revelado; resumo só em encerrada) http://127.0.0.1:8080/api/sessao-ativa.php — devolve só o codigo da sessão não-encerrada mais recente (nunca o token_professor) — é o que tela.php sem código usa http://127.0.0.1:8080/api/qr.php?codigo=8GXACA — PNG gerado na hora (sem depender de internet), aponta pra index.php?s=CODIGO usando o mesmo host:porta que carregou a página

api/entrar.php (POST), api/estado.php?token=... (poll do aluno), api/responder.php (POST) e api/comando.php (POST, ações do professor) não têm um GET útil pra abrir direto — são chamados pelo JS de index.php, prova.php e admin/sessao.php respectivamente.
