QuizSala — Mapa de URLs de teste

Só URLs de teste local por enquanto (servidor php -S na própria máquina). Atualizado em 2026-07-24 com o banco em uso real (não um bin/init-db.php recém-rodado) — por isso os exemplos abaixo já não são a sala-semente AULA01, e sim sessões criadas de verdade pela interface. Código de sala e token do professor mudam a cada sessão nova; a senha do admin não muda (só é gerada na primeira vez, ver seção 4).

Servidor de teste: cd public && php -S 127.0.0.1:8080. Todas as URLs abaixo assumem esse endereço.

1. Aluno

Entrada pública — qualquer um com o código da sala chega aqui.

http://127.0.0.1:8080/index.php

Digitar o código de uma sessão ativa (exemplo de agora: 6PUTWL, em andamento, ou U8T2HB, aguardando o professor iniciar). Depois disso o fluxo continua em prova.php#t=<token do aluno> — token gerado na hora, não é uma URL fixa.

2. Painel do projetor

Tela só de leitura, sem interação — fica projetada na parede. Na fase aguardando mostra o QR Code (T16) em vez da questão.

http://127.0.0.1:8080/tela.php — sem código, acha sozinho a sessão ativa mais recente (novo — descoberta automática, ver seção 5b) e volta a procurar se ela sumir http://127.0.0.1:8080/tela.php?codigo=6PUTWL — código explícito, trava nessa sessão (prova em andamento) http://127.0.0.1:8080/tela.php?codigo=U8T2HB — código explícito, tela de espera com QR

3. Controle do professor (sessão)

Token de sessão — muda a cada sessão nova (admin/nova-sessao.php). Valores de agora:

http://127.0.0.1:8080/admin/sessao.php?codigo=6PUTWL&pt=0e093004f6dac344cec1d27338b0e51a http://127.0.0.1:8080/admin/sessao.php?codigo=U8T2HB&pt=af026d86378f86f14b1b2bc7c9b562ae

Sem o ?pt=... correto, o painel carrega mas nenhum botão funciona (403). Essa tela continua isolada, mobile-first (T22) — não usa o menu lateral do resto do admin.

4. Admin (provas e sessões)

Protegido por senha única (db/admin.senha, fora do git). Essa senha é estável — bin/init-db.php só gera uma nova se o arquivo não existir, então continua valendo mesmo depois de recriar o banco. Valor de agora: 55c2c99472b4af40. Desde o T22, todas as páginas abaixo dividem um menu lateral fixo (src/admin_layout.php).

http://127.0.0.1:8080/admin/index.php — sessões ativas http://127.0.0.1:8080/admin/provas.php — listar/criar/publicar/excluir provas http://127.0.0.1:8080/admin/nova-sessao.php — abrir sessão nova http://127.0.0.1:8080/admin/importar-csv.php — importar prova de CSV http://127.0.0.1:8080/admin/senha.php — trocar a senha do admin (T09e)

5. QR Code (T15)

PNG gerado na hora, sem depender de internet. Aponta pra index.php?s=CODIGO usando o mesmo host:porta que carregou a página.

http://127.0.0.1:8080/api/qr.php?codigo=U8T2HB

5b. Descoberta automática de sessão

Usado por tela.php sem código (seção 2) — devolve só o codigo da sessão não-encerrada mais recente, nunca o token_professor.

http://127.0.0.1:8080/api/sessao-ativa.php
