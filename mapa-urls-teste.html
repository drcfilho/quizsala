QuizSala — Mapa de URLs de teste

Só URLs de teste local por enquanto (servidor php -S na própria máquina). Gerado em 2026-07-24 rodando bin/init-db.php — código de sala e token do professor mudam toda vez que o banco é recriado; a senha do admin não muda (só é gerada na primeira vez, ver seção 4). Rode php bin/init-db.php e olhe a saída no console pra pegar o token atualizado.

Servidor de teste: cd public && php -S 127.0.0.1:8080. Todas as URLs abaixo assumem esse endereço.

1. Aluno

Entrada pública — qualquer um com o código da sala chega aqui.

http://127.0.0.1:8080/index.php

Digitar o código AULA01 no formulário. Depois disso o fluxo continua em prova.php#t=<token do aluno> — token gerado na hora, não é uma URL fixa.

2. Painel do projetor

Tela só de leitura, sem interação — fica projetada na parede.

http://127.0.0.1:8080/tela.php?codigo=AULA01

3. Controle do professor (sessão)

Token de sessão — muda a cada bin/init-db.php. Valor de agora:

http://127.0.0.1:8080/admin/sessao.php?codigo=AULA01&pt=ae3d686c3e6b2bd05b0b35dd4f2752f2

Sem o ?pt=... correto, o painel carrega mas nenhum botão funciona (403).

4. Admin (provas e sessões)

Protegido por senha única (db/admin.senha, fora do git). Essa senha é estável — bin/init-db.php só gera uma nova se o arquivo não existir, então continua valendo mesmo depois de recriar o banco. Valor de agora: 55c2c99472b4af40.

http://127.0.0.1:8080/admin/index.php — sessões ativas http://127.0.0.1:8080/admin/provas.php — listar/criar/publicar/excluir provas http://127.0.0.1:8080/admin/nova-sessao.php — abrir sessão nova http://127.0.0.1:8080/admin/importar-csv.php — importar prova de CSV

5. QR Code (T15)

PNG gerado na hora, sem depender de internet. Aponta pra index.php?s=CODIGO usando o mesmo host:porta que carregou a página.

http://127.0.0.1:8080/api/qr.php?codigo=AULA01
